# Viora v1.0.0 Release Notes

Viora is an AI-powered wellness companion built to help users manage hydration, sleep, nutrition, movement, mental wellness, habits and personal progress in one premium experience.

## Highlights
- Personalized wellness dashboard
- AI Coach with text and native voice interaction
- Hydration, sleep, nutrition and activity tracking
- Yoga, meditation, home workout and music wellness experiences
- Goals, habits, reports and wellness intelligence
- Smart reminders and Android notifications
- AI memory and personalized guidance
- Premium green visual system
- Cinematic Viora launch experience
- Secure role-based admin access
